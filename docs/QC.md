# QC — 출시 전에 뭐 보면 되나

예전에 고친 버그가 **다시 안 나오는지**, 기능이 **지금 문서대로 도는지** 확인하는 메모다. 근거는 [`버전.md`](버전.md)·[`업그레이드.md`](업그레이드.md)·[`방법론.md`](방법론.md)다.

---

## 1. 자동 검사 (먼저)

저장소 루트에서:

```bash
npm ci
npm ci --prefix apps/web
npm run generate:extension-lib
npm test
npm run lint
npm run build:extension
```

**2.2.7 기준:** 위 명령이 모두 통과하면 계약·순수 로직·API·법적 고지 동기화·manifest 경로 등은 코드로 확인된 것이다.

---

## 2. 수동 검사 (쿠팡 + 팝업)

Chrome에서 `apps/extension/`을 **Load unpacked** 한 뒤 한다.

### 팝업

1. 기능이 전부 꺼져 있는지
2. 기능을 하나씩 켜고 끄기
3. 「페이지 표시 항목 조정」 → 체크 해제한 항목만 숨기는지
4. 「의견 보내기」 → 제출 후 목록에 나타나는지

### 쿠팡 검색 (`/np/search`)

| 볼 것 | OK 기준 |
|--------|---------|
| 정렬 | 단위가격·할인율·가격 버튼 동작, 새로고침 후 유지 |
| 정렬 UI | 커스텀 순번만 표시, 해제 시 쿠팡 순번 복구 |
| 확장 아이콘 | 기능 off → 회색, 하나라도 on → 기본 색 |
| 키워드 필터 | 제외 키워드 반영, 검색어 변경 시 초기화 |
| 표시 항목 | 체크 해제 항목만 숨김 |
| 검색 개수 | URL `listSize` 맞춤 |

### 소개 사이트

[altteuri.vercel.app](https://altteuri.vercel.app) → 「최근 의견」만 보이고 작성 칸이 없으면 OK.

### 예전 설치에서 업데이트

- 개별 기능·표시 항목 설정이 유지되는지
- `settingsVersion`이 11인지
- Load unpacked 경로를 `apps/extension/`으로 맞췄는지 (2.2.7부터)

구버전(2.2.0 이전 등)에서 올릴 때는 [`업그레이드.md`](업그레이드.md)도 본다.
