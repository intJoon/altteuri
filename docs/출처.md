# 출처

이 문서는 알뜰이 2.2.6의 외부 자료, 제3자 코드·라이선스, 실제 페이지 관찰 근거를 기록한다. 일회성 실행 로그, CDP 좌표, 폐기된 DOM 셀렉터 목록은 포함하지 않는다.

## 공식 플랫폼 문서

### Chrome Extensions

- Manifest V3 개요: https://developer.chrome.com/docs/extensions/develop/migrate/what-is-mv3
- `chrome.storage`: https://developer.chrome.com/docs/extensions/reference/api/storage
- 콘텐츠 스크립트: https://developer.chrome.com/docs/extensions/develop/concepts/content-scripts
- 원격 호스팅 코드 정책: https://developer.chrome.com/docs/extensions/develop/migrate/remote-hosted-code

적용 범위: 설정은 `chrome.storage`에 두고, 쿠팡 페이지 기능은 Manifest V3 콘텐츠 스크립트로 실행한다. 원격 JavaScript는 불러오지 않는다.

### Vercel과 Neon

- Vercel Functions: https://vercel.com/docs/functions
- Vercel Privacy Notice: https://vercel.com/legal/privacy-notice
- Neon serverless driver: https://neon.com/docs/serverless/serverless-driver
- Neon Privacy Policy: https://neon.tech/privacy-policy
- Neon Data Processing Addendum: https://neon.tech/dpa

적용 범위: 의견 API는 Vercel 서버리스 + Neon PostgreSQL이다. 위탁·국외 이전 세부는 [`개인정보처리방침.md`](개인정보처리방침.md)를 따른다.

## 쿠팡 페이지 관찰 근거

알뜰이는 쿠팡과 제휴하지 않았으며, 아래 내용은 공개 페이지 또는 사용자가 제공한 마크업을 기능 호환성 확인 목적으로 관찰한 결과다. 쿠팡의 공식 API 계약이 아니므로 언제든 변경될 수 있다.

### 검색 결과

- 상품 목록은 `#product-list`, 상품 카드·상품명은 `ProductUnit_*` 계열을 기준으로 찾는다.
- 2026-07-12 이후 판매가·할인율·단위가는 텍스트 패턴(`12,900원`, `13%`, `(100g당 516원)` 등)을 주 기준으로 사용한다.
- 검색어는 `/np/search`의 `q`, 검색 개수는 `listSize`를 사용한다.
- 2026-07-23 관찰: 검색 결과 「오늘의 판매자 특가」 캐러셀은 `div.todays-sale`(`carousel-widget-container.gw_promotion` 포함)로 구분한다. 상품 상세의 동명 블록은 `div.product-btf-container` 아래에 있다. `/np/search?q=컴퓨터` 기준 위→아래 순서는 상단 배너 → 브랜드 배너 → (있을 때) 맞춤 상품 광고 → 그리드 광고·베스트/한정 특가(목록 안) → 같이 보면 좋은 상품 → 로켓직구 글로벌특가 → 함께 본 상품 → **오늘의 판매자 특가(맨 아래)**.

### 표시 항목 프리셋

2026-07-11~16 관찰을 바탕으로 `extension/preset-data.js`에 검색·상세·장바구니·주문목록의 광고·추천·프로모션 영역을 반영했다. 셀렉터와 항목명은 해당 파일을 우선한다. 셀렉터를 수정할 때는 [`QC.md`](QC.md)의 DOM 점검 항목과 `tools/tests/extension/selector-smoke.test.mjs`를 함께 갱신한다.

## 유지보수 기준

- 외부 문서의 URL·정책·라이선스는 의존성이나 법적 고지를 변경할 때 다시 확인한다.
- 쿠팡 DOM 관찰은 날짜와 대상 페이지를 남기되, 재현에 필요하지 않은 좌표·세션·실행 로그는 커밋하지 않는다.
- 외부 코드를 추가하거나 이식하면 실제 사용 여부, 버전, 저작권자, 라이선스 고지를 함께 갱신한다.
